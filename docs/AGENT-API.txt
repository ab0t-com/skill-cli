skills — runtime API for AI agents
  (operator commands like install/rename/audit/scan are at `skills help`)

DISCOVERY
  skills discover "<user prompt>" --json
    Routes a user prompt to the right skill(s).
    Returns: { decision: "select"|"no-skills"|"missing-skill",
               confidence: "high"|"medium"|"low",
               reasoning_summary, selected_skills, missing_skill, ... }
    Cost: ~$0.01 with Sonnet, ~$0.003 with Haiku. Single API call.

  skills similar <name> --json
    Top-5 most-similar skills (Jaccard on description tokens + tag overlap).
    Returns: { target, target_category, target_tags, results: [{name, score,
               category, tags, shared_tags, description_jaccard, tag_jaccard}] }
    Read-only, no API call. Use after loading one skill to find related context.

CATALOG
  skills manifest
    Full catalog. Always JSON.
    Returns: [{name, description, category, tags}, ...]

  skills list --json
    Same as manifest but with install_state per skill.
    Returns: [{name, description, category, tags, install_state}, ...]

PROMPT TEMPLATES
  skills prompt render <name> [--vars '<json>']
    Hydrate a Jinja2 template. Returns rendered text on stdout.
    Missing vars degrade gracefully (Jinja2 ChainableUndefined → empty string).

  skills prompt body <name>
    Raw pre-render template body. Useful for inspecting Jinja2 syntax + the
    schema declared in frontmatter before deciding what vars to pass.

  skills prompt show <name>
    Full file (frontmatter + body) for inspection.

CONVENTIONS
  • Read-only — no skill mutation. Operator-only commands are blocked with clear errors.
  • All accept --json for stable structured output.
  • Errors emit { "error": "...", ... } to stderr; exit code non-zero.
  • Non-zero exits indicate failure; check exit code AND parse stdout JSON.
  • `skills manifest` is cheap; cache once per session/conversation.

AGENT CALL CHAIN EXAMPLE
  # 1. Route the user prompt
  decision=$(skills discover "$USER_PROMPT" --json)
  # 2. Find sibling skills if needed
  similar=$(skills similar $(echo "$decision" | jq -r '.selected_skills[0].name') --json)
  # 3. Hydrate a templated prompt for an agent-dispatched sub-task
  prompt=$(skills prompt render create-service-api-reference-skill --vars '{"service_name":"foo"}')

NOT FOR AGENT USE (have side effects, prompts, or irreversible state changes)
  install, add, remove, scan, secrets, snapshot, drift, audit, rename, doctor,
  setup, open, new, classify, categorize, tag, prompt edit, prompt history.
  These are curator commands — agents should not invoke them in a loop.
